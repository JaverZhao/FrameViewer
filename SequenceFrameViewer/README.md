# FrameView

Windows 轻量化序列帧查看工具。

快速预览 PNG / JPG / WebP / BMP 序列帧动画。

## 功能

- 打开文件夹 / 拖拽文件夹打开序列帧
- 自动扫描并自然排序序列帧
- 播放 / 暂停 / 上一帧 / 下一帧 / 首帧 / 尾帧
- FPS 设置（1-120，默认 24）
- 循环播放
- 时间轴滑块拖动跳帧
- 鼠标滚轮缩放 / 鼠标拖动画布
- 适配窗口 / 原始大小
- 透明 PNG 棋盘格背景（支持黑/白/灰/棋盘格切换）
- 帧缓存与预读（LRU 缓存策略）
- 文件夹内容变化自动刷新
- 最近打开文件夹记录
- 键盘快捷键
- 深色主题

## 使用

1. 点击"打开文件夹"或拖拽文件夹到窗口
2. 点击 ▶ 开始播放
3. 滚轮缩放，拖动平移

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Space | 播放 / 暂停 |
| ← → | 上一帧 / 下一帧 |
| Home / End | 首帧 / 尾帧 |
| Ctrl+O | 打开文件夹 |
| Ctrl+R | 重新加载 |
| F | 适配窗口 |
| 1 | 原始大小 |

## 系统要求

- Windows 7 及以上
- .NET 7 运行时（或使用 self-contained 发布版本）

## 技术栈

- C# / WPF
- .NET 7
- MVVM (CommunityToolkit.Mvvm)
- 原生 WPF 图片解码 (WIC)
